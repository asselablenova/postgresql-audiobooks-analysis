# Анализ пользовательского поведения и контента в сервисе аудиокниг (PostgreSQL)

## 📌 Бизнес-контекст проекта
Проект посвящен продуктовой аналитике платформы для чтения книг и прослушивания аудиокниг (веб и мобильные приложения).

**Особенности бизнес-модели:**
* **Монетизация:** Freemium-модель. Бесплатный доступ открыт к книгам в общественном достоянии (public domain) и загруженным файлам. При прочтении или прослушивании **более 10%** платного контента срабатывает пэйвол (paywall) с предложением автопродлеваемой подписки (книги, аудиокниги или комбо).
* **Юнит-экономика и привлечение:** 50% выручки от подписок выплачивается правообладателям (revenue share). Трафик — органический (поиск и рейтинги сторов) и платный (модель pay-per-install).

## 🛠 Стек технологий
* **СУБД:** PostgreSQL
* **Инструменты:** pgAdmin 4

---

## 🗄 Структура базы данных (`test_db`)

В проекте используются данные о каталоге аудиокниг, пользовательских библиотеках и сессиях прослушивания:
* `audiobooks` — справочник аудиокниг (`uuid`, `duration` в секундах, `title`).
* `audio_cards` — карточки книг, добавленных в библиотеку пользователя (`id`, `user_id`, `state`, `progress`, `audiobook_uuid`).
* `listenings` — логи сессий прослушивания (`id`, `user_id`, `audiobook_uuid`, `os_name`, `started_at`, `finished_at`, `is_test`, `position_from`, `position_to`, `speed_multiplier`).

## 🎯 Аналитические задачи и решения (SQL)

### 1. Воронка вовлечения на примере книги «Coraline»
**Задача:** Вывести количество пользователей, добавивших книгу в библиотеку, и количество пользователей, прослушавших более 10% (точка показа пэйвола).

```sql
SELECT 
    COUNT(DISTINCT ac.user_id) AS added_users_count,
    COUNT(DISTINCT CASE WHEN ac.progress > 0.1 * b.duration THEN ac.user_id END) AS listened_over_10_pct_count
FROM audio_cards ac
JOIN audiobooks b ON ac.audiobook_uuid = b.uuid
WHERE b.title = 'Coraline';

# Ключевые выводы (Инсайты)Воронка книги «Coraline»:
# Книгу добавили в библиотеку 199 пользователей. Из них до рубежа в 10% (момент срабатывания paywall) дошли 38 пользователей, что формирует конверсию вовлечения в ключевое продуктовое действие примерно в 19.1%.
# Анализ платформ (ОС): Основная масса пользователей распределена между платформами Android и iOS. Например, по книге «Sapiens. Краткая история человечества» зафиксировано максимальное суммарное время прослушивания (около 1201.8 часов на Android и 1596.8 часов на iOS).
# Самый популярный контент по охвату: Абсолютным лидером по количеству уникальных слушателей является книга «The Subtle Art of Not Giving a F...», собравшая вокруг себя 1133 уникальных пользователя.
# Лидер по дослушиваемости: Эта же книга («The Subtle Art of Not Giving a F...») удерживает лидерство по числу успешных завершений — её дослушали до конца 86 уникальных пользователей.
